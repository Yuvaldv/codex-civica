Privacy Policy

Last updated: 2026-08-09

Overview​

Codex Civica is a static site: it publishes legislative reference content and does not require you to create an account, log in, or submit personal information to read it.

Information we collect​

We do not operate our own tracking, analytics, or advertising scripts on this site, and we do not set first-party cookies. We do not collect names, email addresses, or other personal data through the site itself.

Hosting​

This site is hosted on GitHub Pages. Requests to load the site pass through GitHub's infrastructure, which may log standard web request data (such as IP address, browser type, and request time) as part of its own hosting operations. That processing is governed by GitHub's Privacy Statement, not by us.

Third-party links​

Pages on this site may link to official government sources or to our GitHub repository. Those third-party sites have their own privacy practices, which we do not control.

Children's privacy​

This site does not knowingly collect personal information from anyone, including children, because it does not collect personal information in the first place.

Changes to this policy​

If the site's data practices change (for example, if analytics are introduced in the future), this page will be updated to reflect that, along with the "last updated" date above.

Contact​

Questions about this policy can be raised via GitHub Issues.
