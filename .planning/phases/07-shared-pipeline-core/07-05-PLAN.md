## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline to external process (`npm run deploy`) | Subprocess boundary carrying the full inherited environment, including any secret loaded by `dotenv` earlier in the same process |
| pipeline to production GitHub Pages | `npm run deploy` publishes to the `gh-pages` branch; push to `main` also auto-deploys |
| `common/` to Israel modules | One-way dependency edge, statically enforced |
