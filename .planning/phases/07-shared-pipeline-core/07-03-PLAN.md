<interfaces>
Contract being moved (identical in both modules; verified AST-identical and differentially
identical over 112 files plus 6 edge cases):

  split_frontmatter(text: str) -> tuple[str, str]
      returns ("", text) when text does not start with "---" or has no closing fence;
      otherwise returns (frontmatter_block_including_fences_and_trailing_newlines, body)

Current definitions and call sites (line numbers verified in the working tree 2026-08-09):
  pipeline/link_resolver.py  def split_frontmatter   line 27   call site line 216
  pipeline/cross_linker.py   def _split_frontmatter  line 202  call site line 217

Import mechanics (empirically probed, and per docs.python.org/3/library/sys_path_init.html):
  sys.path[0] is the directory of the executed script, so `python pipeline/link_resolver.py`
  makes `pipeline/` the root and `from common.frontmatter import ...` resolves. This is
  cwd-independent. `python -m pipeline.link_resolver` is NOT a supported invocation form in this
  repo and never was — do not try to make it work.
